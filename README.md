# RekoMed: Инструкция Для Пользователя Админки

Это инструкция для менеджера, редактора или администратора сайта RekoMed. Здесь описано, как зайти в админку, где менять данные, как добавлять товары, документы, бренды, статьи и как настраивать получение заявок.

## 1. Адреса

Сайт:

```text
https://reko-med.ru/
```

Админка:

```text
https://reko-med.ru/admin
```

Локальная админка для разработки:

```text
http://localhost:3000/admin
```

Если админка открывается впервые, система предложит создать первого пользователя. Создайте администратора с рабочей почтой и надёжным паролем.

## 2. Важный Статус Текущей Версии

Админка Payload подключена и готова для управления товарами, категориями, брендами, документами, статьями, заявками и настройками.

Публичная витрина читает товары, категории и бренды из Payload CMS. Импортированный каталог из старого сайта `src/data/current-site.generated.ts` остается fallback-слоем: он сохраняет legacy URL и наполняет витрину, если CMS или PostgreSQL временно недоступны.

Товар, добавленный в `Products`, появляется на публичной странице по `Legacy Path` или по адресу `/catalog/{slug}/`.

## 3. Вход В Админку

1. Откройте `/admin`.
2. Введите email и пароль.
3. Нажмите вход.

Если пароль потерян, обратитесь к техническому администратору проекта. Не создавайте второго администратора без необходимости.

## 4. Основные Разделы Админки

В админке есть такие сущности:

- `Users` — пользователи админки.
- `Media` — изображения, PDF, документы и файлы.
- `Directions` — направления: остеосинтез, эндопротезирование, нейрохирургия и т.д.
- `Categories` — категории каталога.
- `Products` — товары.
- `Brands` — производители и бренды.
- `Documents` — РУ, сертификаты, инструкции, каталоги.
- `Articles` — статьи и новости.
- `Leads` — заявки с сайта.
- `Site Settings` — глобальные контакты и настройки.

## 5. Как Добавить Товар

1. Откройте `/admin`.
2. Перейдите в раздел `Products`.
3. Нажмите `Create New`.
4. Заполните основные поля:
   - `Title` — название товара.
   - `Slug` — адресная часть латиницей, например `shtift-dlya-plecha`.
   - `Legacy Path` — старый URL, если товар должен заменить старую страницу, например `/catalog/shtift/401/`.
   - `External ID` — старый ID или артикул, например `401`.
   - `Description` — описание товара без медицинских обещаний.
   - `Category` — категория товара.
   - `Brand` — производитель или бренд.
   - `Image` — изображение товара.
5. В блоке `Attributes` добавьте характеристики:
   - `Материал` — например `Титановый сплав`.
   - `Длина` — например `200-300 мм`.
   - `Диаметр` — например `8,0-9,0 мм`.
   - `Толщина`, `Кол-во отв.`, `Страна производства` и другие параметры.
6. В `Documents` привяжите сертификаты, РУ, инструкции или каталоги.
7. В блоке SEO заполните:
   - `Meta Title`;
   - `Meta Description`;
   - `Canonical Path`;
   - `Indexable`.
8. Сохраните товар.

Рекомендация: для B2B-аудитории описание должно помогать менеджеру или закупщику понять, что это за изделие, какие есть параметры и какие документы можно запросить.

## 6. Как Изменить Товар

1. Откройте `Products`.
2. Найдите товар по названию, slug, артикулу или ID.
3. Откройте карточку.
4. Измените нужные поля.
5. Сохраните.

Изменения появляются на сайте после обновления страницы. Если PostgreSQL временно недоступна, сайт продолжит показывать импортированный legacy-каталог.

## 7. Как Добавить Категорию

1. Откройте `Categories`.
2. Нажмите `Create New`.
3. Заполните:
   - `Title` — название категории.
   - `Slug` — латинский slug.
   - `Legacy Path` — старый URL, например `/catalog/plastiny/`.
   - `Description` — краткое описание ассортимента.
   - `Direction` — направление, к которому относится категория.
4. Заполните SEO-поля.
5. Сохраните.

## 8. Как Добавить Направление

1. Откройте `Directions`.
2. Нажмите `Create New`.
3. Заполните:
   - `Title` — например `Изделия для остеосинтеза`.
   - `Slug` — например `osteosintez`.
   - `Summary` — короткое описание направления.
   - `CTA Type` — тип основной заявки.
4. Заполните SEO-поля.
5. Сохраните.

Направления нужны для посадочных страниц и верхней структуры сайта.

## 9. Как Добавить Бренд Или Производителя

1. Откройте `Brands`.
2. Нажмите `Create New`.
3. Заполните:
   - `Title` — название бренда.
   - `Slug` — латиницей.
   - `Description` — описание бренда и ассортимента.
   - `Logo` — логотип, если есть.
4. Заполните SEO-поля.
5. Сохраните.

После этого бренд можно привязывать к товарам.

## 10. Как Добавить Документ

1. Сначала загрузите файл в `Media`, если он ещё не загружен.
2. Откройте `Documents`.
3. Нажмите `Create New`.
4. Заполните:
   - `Title` — понятное название документа.
   - `Kind` — тип документа:
     - `registration` — регистрационное удостоверение;
     - `certificate` — сертификат;
     - `instruction` — инструкция;
     - `catalog` — каталог;
     - `other` — другое.
   - `File` — выберите файл.
   - `Related Products` — привяжите товары, если документ относится к конкретным изделиям.
5. Сохраните.

Не загружайте устаревшие документы без пометки и проверки.

## 11. Как Добавить Статью Или Новость

1. Откройте `Articles`.
2. Нажмите `Create New`.
3. Заполните:
   - `Title`;
   - `Slug`;
   - `Excerpt`;
   - `Content`;
   - `Published At`;
   - SEO-поля.
4. Сохраните.

Для медицинской тематики не используйте обещания результата лечения. Пишите экспертно и проверяемо.

## 12. Как Смотреть Заявки

Основное место работы с заявками — админка, раздел `Leads`.

Если человек отправил форму со страницы товара, в заявке автоматически сохраняются:

- название товара;
- артикул;
- категория;
- ссылка на товар;
- страница, с которой отправили форму.

Также заявка отправляется Борису в VK, если VK-доставка включена в `Site Settings` и технический администратор один раз прописал `VK_GROUP_TOKEN` на сервере.

Файл `var/leads.jsonl` используется только как аварийный fallback, если CMS временно недоступна.

Поля заявки:

- имя;
- телефон;
- email;
- комментарий;
- страница сайта;
- товар, артикул, категория и ссылка на товар, если заявка отправлена из карточки товара;
- статус доставки в VK;
- статус.

Рекомендуемый процесс обработки:

1. Открыть заявку.
2. Связаться с клиентом.
3. Уточнить товар, документы или КП.
4. Изменить статус заявки на `processing`.
5. После обработки поставить статус `done`.

## 13. Как Настроить VK Для Заявок

Откройте `Site Settings`.

Поля:

- `Vk Lead Enabled` — включить или выключить отправку заявок в VK;
- `Vk Recipient Peer ID` — ID диалога или пользователя Бориса;
- `Vk Lead Message Template` — шаблон сообщения.

Токен VK-сообщества (`VK_GROUP_TOKEN`) хранится на сервере и меняется техническим администратором. Это сделано специально, чтобы секретный токен не был виден редакторам сайта.

Если VK временно недоступен, заявка всё равно сохраняется в `Leads`, а в полях доставки будет видна ошибка.

## 14. Как Включить JivoChat

Откройте `Site Settings`.

Поля:

- `Jivo Enabled` — включить или выключить чат;
- `Jivo Widget ID` — ID виджета из кабинета JivoChat.

Вставлять полный HTML/script-код не нужно. Достаточно указать ID виджета.

## 16. Как Настроить SEO, Метрики И Юридические Страницы

Откройте `Site Settings`.

Что заполняет владелец сайта:

- `Yandex Metrika ID` — только номер счетчика, без HTML-кода;
- `Yandex Verification` и `Google Site Verification` — коды подтверждения владения сайтом;
- `VK Page URL` — публичная ссылка на страницу VK;
- `Legal Name`, `INN`, `OGRN`, `Legal Address` — реквизиты компании;
- `Privacy Policy Text` — полный текст политики обработки персональных данных для `/privacy/`;
- `Personal Data Consent Text` — полный текст согласия для `/consent/`;
- `Terms Text` — полный текст пользовательского соглашения для `/terms/`;
- `Additional Legal Information Text` — дополнительный текст для страницы `/legal/`;
- `License Text` и `License File` — текст и файл лицензии или документа, если есть;
- `Cookie Banner Enabled` и `Cookie Banner Text` — управление баннером cookie;
- `Medical Disclaimer Text` — медицинский дисклеймер внизу сайта.

Публичные страницы уже доступны:

```text
/privacy/
/consent/
/terms/
/legal/
/license/
```

Яндекс.Метрика загружается только после нажатия `Принять` в cookie-баннере. Если посетитель нажал `Отклонить`, счетчик не подключается.

## 17. Как Поменять Тексты На Главной

Текущая главная собрана в коде:

```text
src/components/templates.tsx
```

Для изменения текстов на главной обратитесь к разработчику. В CMS уже есть сущности для будущего управления контентом, но главный экран пока не вынесен в редактор.

## 18. Как Проверить, Что Сайт Работает

Публичные проверки:

```text
https://reko-med.ru/
https://reko-med.ru/catalog/
https://reko-med.ru/catalog/shtift/401/
https://reko-med.ru/robots.txt
https://reko-med.ru/sitemap.xml
https://reko-med.ru/api/health
```

Что должно быть:

- главная открывается;
- каталог открывается;
- товарная карточка открывается;
- форма заявки отправляется;
- `robots.txt` содержит ссылку на sitemap;
- sitemap открывается;
- `/api/health` возвращает `{"ok":true}`.

## 19. Как Запросить Изменение На Сайте

Для разработчика полезно сразу передавать:

- какую страницу изменить;
- какой текст сейчас;
- какой текст должен быть;
- нужен ли новый товар, категория, документ или блок;
- должен ли URL сохраниться;
- нужен ли редирект со старого URL;
- какие документы или изображения приложены.

## 20. Правила Контента

- Не обещайте медицинский результат.
- Не пишите "лечит", "гарантирует восстановление", "лучший метод лечения".
- Пишите про изделие, параметры, документы, поставку, наличие и подбор.
- Для товара указывайте только проверяемые характеристики.
- Для документов проверяйте актуальность.
- Для SEO не создавайте пустые страницы без полезного описания и CTA.

## 21. Короткий Чеклист Для Нового Товара

Перед сохранением проверьте:

- есть понятное название;
- выбранная категория правильная;
- добавлены основные характеристики;
- привязан бренд, если известен;
- добавлены документы, если есть;
- заполнены SEO title и description;
- нет медицинских обещаний;
- указан старый URL в `Legacy Path`, если товар заменяет старую страницу.
